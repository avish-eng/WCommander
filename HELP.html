Multi-Pane Commander

Command list. The active pane is the pane with focus.

Function Keys

F1Open this help
F2Rename selected item
F3Quick View in the passive pane
F4Edit selected file
F5Copy to passive pane
F6Move to passive pane
F7Create directory
F8Delete selected items
F9Show or hide terminal
F10Open main menu
F11Layout menu
F12Jobs view

Navigation

TabSwitch active pane
EnterOpen file or enter directory/archive
BackspaceGo to parent directory
InsertMark or unmark item
SpaceMark item; on a directory, compute size
Alt+ArrowMove focus by pane direction
Alt+F1/F2Drive menu for active/passive pane
Alt+7Use a compact left-pane window; F9 adds the terminal below it

Tools

Ctrl+SQuick filter current pane
Ctrl+MMulti-rename
Ctrl+ZUndo last rename
Alt+F7Find files
Ctrl+RRefresh active pane
Ctrl+PEdit process PATH
Ctrl+KOpen AI command palette
Ctrl+GFocus command bar
