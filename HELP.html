Multi-Pane Commander

A practical guide to files, terminal, layouts, themes, and Claude Code.

1. Choose a sourceClick a pane and select the files you want to work with.
2. Choose a destinationThe other pane is the default destination for copy and move.
3. Use the keyboardF5 copies, F6 moves, and F8 deletes.

Core file actions

F1Open this help
F2Rename the selected item
F3Show or hide Quick View in the passive pane
F4Edit the selected file
F5Copy selected or marked items to the passive pane
F6Move selected or marked items to the passive pane
F7Create a directory
F8Delete selected or marked items
Shift+F8Permanently delete, bypassing the Recycle Bin
Ctrl+MMulti-rename marked or selected items with a live preview
Ctrl+ZUndo the last supported file operation

Marked items take priority. If nothing is marked, the item under the cursor is used.

Embedded terminal

Standard terminal and Classic controls share a terminal core and bundled renderer. Choose a preference under Layout (F11) → Terminal compatibility (next launch). Mode and backend preferences apply on the next launch, preserving the current session.

F9Show or hide the terminal
Ctrl+`Show or hide the terminal
Ctrl+Shift+`Enter or exit terminal full screen
Ctrl+EnterPaste the current file name into the terminal
Alt+EnterPaste the current item's full path into the terminal
Ctrl+Shift+KInterrupt the current terminal program, escalating to stop if needed
Ctrl+FSearch terminal output (standard terminal)
Ctrl+= / Ctrl+- / Ctrl+0Font zoom (standard terminal)
Ctrl+Insert / Shift+InsertCopy / paste (standard terminal)
Ctrl+CCopy when text is selected, otherwise send interrupt
Ctrl+VPaste into the terminal
Ctrl+GFocus the command bar
  • The terminal follows the active pane's directory by default. Directory changes wait for a detected prompt with no unfinished input. Switching to Independent cancels a pending directory change.
  • The standard terminal also understands OSC 7 / OSC 9;9 / OSC 133 shell integration when your shell emits it, and skips redundant directory changes.
  • Right-click the terminal for Copy / Paste / Select all / Find / Clear / Interrupt / Kill / Restart.
  • Pinned commands appear at the top of the history list. Only commands launched through the app or reported by shell integration are saved; ordinary terminal input is not recorded. Running or loading a saved command requires an idle shell with an empty prompt.
  • The terminal backend name, such as ConPTY, appears at the end of the status line.

Claude Code and AI

Navigate the active pane to the project directory, then press Ctrl+Shift+C. Claude Code opens in the passive pane and uses the active directory as its working directory. Press the shortcut again to close it. Use New Session inside the Claude pane when you want a fresh conversation.
Ctrl+Shift+COpen or close the embedded Claude Code terminal
Ctrl+KOpen the AI command palette
Ctrl+IToggle AI summary mode for the current Quick View file
Ctrl+Shift+IShow or hide the AI pane

Claude features require the claude CLI to be installed, logged in, and available on PATH.

Themes

  • Open the theme editor from the application menu to preview and customize a theme.
  • Save Theme stores your edited colors as a custom theme.
  • Make Default selects the theme used when the application starts.
  • Delete Theme removes custom or built-in themes from the theme list.
  • Deleted themes are exported to the backup themes folder before removal so their definitions can be recovered manually.
Permanent deletion cannot be undone. Use F8 for normal deletion and reserve Shift+F8 or Shift+Delete for files you are certain you no longer need.
