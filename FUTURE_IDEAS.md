# Future Ideas

- Richer media preview, especially video preview and stronger document preview support.
- On `Enter` for a file, open it with the default application registered by Windows.
- On file right-click, show the Windows-registered "Open with" program list and let the user choose which app to launch.
- Optional shell-integration bootstrap for bash/zsh/pwsh so the Deep Terminal can report exit codes and command lines exactly, instead of relying on prompt heuristics.
- Split panes inside the terminal (multiple shells in one dock).
- Terminal profile support (different shells, starting directories, and themes per tab).
- Kitty graphics / inline images in the terminal.

Terminal `Tab` autocomplete is already native in the Deep Terminal: Tab is forwarded to the shell and the app disables its pane-switch shortcut while the terminal has focus.
